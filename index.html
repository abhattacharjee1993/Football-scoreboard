Sports Unplugged India | Master User Manual

Welcome to the Ultimate Broadcast Overlay. This highly customizable, real-time sports graphic suite runs entirely in your browser. Below is everything you need to operate it perfectly for your live streams.

I. System Setup & Views

The system works using a primary/secondary window structure connected via the cloud in real-time:

  • Control Panel (Your Screen): Open the main HTML file normally in your web browser (Chrome recommended). This is where you click buttons, update scores, and style the layout.
  • Live Overlay (Audience Screen): In OBS, vMix, or Streamlabs, add this HTML file as a Browser Source. Crucially, append ?view=overlay to the end of the file path (e.g., C:/path/to/index.html?view=overlay). The massive control panel will automatically hide, leaving only the transparent broadcast graphics.

II. Instant Updates vs. The SYNC Button

To prevent viewers from seeing you awkwardly drag sliders or change colors live on stream, the panel uses a dual-sync architecture:

  • Instant Actions: Modifying the Score, pressing Play/Pause on the clock, adding Red Cards, clicking Penalty Bulbs, toggling element visibility (Show/Hide Scoreboard), and Auto-Extracting Image text. These send immediately to the stream.
  • Draft Actions (Requires SYNC): Changing fonts, text size sliders, team names, background colors, scale, and gradient toggles. These will update only on your local preview so you can make them look perfect. When you are ready, you must click the yellow "SYNC LAYOUT TO STREAM" button at the top to push these visual changes to your audience.

III. Core Control Panels

1. Scoreboard Controls

  • Clock Options: Standard play/pause. Use the reset buttons (0', 45', 90') to jump to standard half starts. Use Custom Time for precise overrides (Format: MM:SS). Click + Injury to add stoppage time to the right of the clock. Click match phases (HT, FT, PEN) to replace the clock text entirely.
  • Scores & Red Cards: Use the massive Score buttons and +/- Red Card buttons for instant updates.
  • Memory List: When setting up a team, enter their name, assign colors, and click "Save to Memory". Next time you type that team name, it will auto-complete.
  • Visuals: Change backgrounds (Solid vs Split vs Gradient). Pick from 19 Google Fonts for the team names, score, and timer. Independently resize logos.

2. Target Box Controls

  • Controls the Like/Sub goal widget in the top right. (Note: The Subscriber counter box on the left is automated directly from YouTube).
  • You can type numbers in manually, customize the font type for the labels vs. numbers, and edit the two-tone gradient background.

3. Playing 11 Lineup Controls

  • Auto-Extract Image (OCR): You no longer need to type lineups manually. Click this button, select a screenshot of the team sheet, and the built-in AI will read the image and paste the names into the box for you.
  • Use the visual layout sliders to change panel width, typography, opacity, and toggle whether the team logo is visible at the top of the lineup card.

4. Bottom Ticker Controls

  • Toggle the visibility, choose between a solid block or gradient background, and edit the text.
  • Scroll Animation: Checking this makes the text continuously loop across the bottom of the screen. Unchecking it centers the text statically.

5. Penalty Shootout Controls

  • Click Enable Penalty Drop-down to reveal the penalty phase UI. This reveals a sleek shootout bar under the main scoreboard, brackets next to the main score, and a larger summary board at the bottom center.
  • The Matrix: Add or remove bulbs based on how many shots are being taken (default is 5).
  • Clicking Bulbs: Click a bulb to instantly cycle its state: Gray (Empty) ➔ Green (Scored) ➔ Red (Missed). The score in brackets will calculate automatically.

IV. Layout Management & Recovery

  • Undo/Redo System: Any visual change you make (sliders, dropdowns, colors) is tracked. If you mess up a layout visually, hit Undo to jump back a step.
  • Save / Save As: Perfectly customized a layout for a specific league (e.g., ISL colors and fonts)? Hit "Save As", name it "ISL Preset", and it will be saved to your browser's local storage.
  • Load: Use the Load menu to search for your saved presets and immediately swap out colors, fonts, and slider sizes in a single click.

V. UI Interaction Tips

  • Draggable Interface: Click and drag the top header ("MASTER CONTROL SUITE") to move the massive widget out of your way to check your stream preview beneath it.
  • Minimize Panel: Click this button to collapse the widget entirely, keeping only the top header bar visible.
  • Accordion Menus: Click any of the 5 section headers to collapse/expand them to keep your workspace tidy.
