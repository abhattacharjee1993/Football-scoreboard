Sports Unplugged India | User Manual

Overview

This Ultimate Broadcast Overlay is a two-part system designed for live sports broadcasting. You must open this file twice:

  • Control Panel (Your view): Open the file normally in your browser. Use this window to manage the match, update scores, and change layouts.
  • Live Overlay (Audience view): Add this file to OBS/vMix/Restream as a Browser Source, and append ?view=overlay to the end of the file path. The Control Panel will hide automatically, displaying only the transparent graphics.

1. Instant vs. Sync Actions

Instant Actions (No Sync Needed): Changing scores, updating clock, adding red cards, toggling elements (Show/Hide Scoreboard, Target Box, Ticker, Penalties), typing names/lineups, extracting text via image, and clicking penalty bulbs. These update live on the stream instantly.

Layout Actions (Requires Sync): Dragging sliders (size, position), changing fonts, selecting colors. These preview locally on your Control Panel. Once satisfied, click "SYNC LAYOUT TO STREAM" to push changes live.

2. Scoreboard Controls

Manage the main match here. Click "Play/Pause" for the clock, add goals using the +/- buttons, and set match phases (HT, FT). Red card buttons (+/-) instantly appear above the team names. You can also upload custom Team and Tournament logos.

Pro Tip: Use the "Save to Memory" button next to a team name to save it for future streams. It will autocomplete when you type it next time!

3. Playing 11 / Lineup Controls

Enter lineups manually or click "Auto-Extract Image" to upload a screenshot of the playing 11. The built-in OCR AI will automatically read the names from the image and paste them into the box. Just click out of the box to instantly broadcast them to the screen.

4. Ticker & Target Box

The Bottom Ticker scrolls an editable message across the bottom. The Target Box can display Like and Subscriber goals. Toggle them on/off instantly and customize their background gradients and text sizing before syncing.

5. Penalty Shootout Controls

Click "Enable Penalty Drop-down" to reveal the shootout bar attached to the scoreboard, plus a larger penalty summary graphic. Click the circular bulbs to cycle their status: Gray (Empty) ➔ Green (Scored) ➔ Red (Missed). Brackets with the penalty scores will appear automatically next to the main score.

6. Layout Memory System (Undo/Redo & Save)

Any visual layout tweaks (sizes, fonts, colors) are tracked. You can hit Undo/Redo to revert local layout mistakes. Once perfectly set up, click Save As to save your customized layout for specific leagues (e.g., "ISL Preset"). Use Load to quickly hot-swap between your saved presets.

7. Minimizing the Panel

Click "Minimize Panel" to collapse the massive dashboard. You can click and drag the "MASTER CONTROL SUITE" header to move the widget out of your way to see your stream preview clearly.
